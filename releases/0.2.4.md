# Asteroid Erosion 0.2.4

Adds compatibility with **EveJS 261115.2 on Windows Native**.

- Authored mission rocks marked as fixed-size now keep their intended radius
  while being mined. Ordinary ore asteroids still shrink normally.
- Supports the updated native mining and login hooks while preserving the
  native GM health-window delivery.
- Existing server configuration and personal visual preferences are retained.
  No mod save migration is required.

Validated with the actual Windows Native server and retail client, including
mining, shrinking/dust, partial and depleted stock across same-world cold
restarts, combined mods and reconnect. The combined check captured shrinking
and matching models; its short dust burst was not sampled. Dust was verified
in the separate individual run. No new Docker or Linux runtime support is claimed.

**Install/update:** close EVE and stop the game server, then update Asteroid
Erosion through the Launcher's **Mods** page. For a new installation, use
**Mods -> Add ZIP** with `AsteroidErosion-0.2.4.zip`. Start the server and fully
reopen EVE afterwards so the updated companion is delivered at login.

The installable ZIP preserves the exact qualified bytes. Its embedded
preparation-time status wording is superseded by this release and the
[completed qualification record](https://github.com/V0nCleef/EveJS-Asteroid-Erosion/blob/v0.2.4/docs/compatibility-261115.2.md).
