# Asteroid Erosion 0.2.2 — EveJS 261028.1 compatibility

Radius changes now use EveJS 261028.1's native Destiny tick history and bubble
batches. This restores intermediate shrink updates when the old immediate-send
API is absent, while native delivery handles observer visibility, tick stamps
and missed-batch recovery. The removed `sendOptions.js` helper is no longer
required on 261028.1; older supported builds retain their legacy delivery path.

- Preserves configuration, personal settings, dust, all four depletion styles,
  native terminal effects and shared MODS menu composition. Client source is
  unchanged.
- Supports EveJS **0.12.9, 261018.1 and 261028.1 Native**, with Launcher 1.0.69+.
- Update through the Launcher; stop the Game server for installation, then
  restart it and fully reopen clients. `config.json` is preserved, and personal
  preferences remain in the client's per-character settings.

Validation: 22 focused server/native-boundary checks, 42 client-contract replays
and 12 UI replays passed, plus focused legacy-version checks. The installed
loader was also probed through the actual native queue and wire encoder. The
user reported Erosion working and subsequently confirmed that the updated mods
seem to work in gameplay; this is user-reported confirmation, separate from the
automated checks. No Docker, extended multiplayer matrix or soak test is claimed.
