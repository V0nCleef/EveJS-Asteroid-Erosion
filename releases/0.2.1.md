# Asteroid Erosion 0.2.1

Adds reviewed EveJS 261018.1 support while retaining 0.12.9. The loader now checks actual source seams instead of rejecting an unfamiliar version label; unknown source changes still stop it safely. Native Homefront mining callbacks and AutoMining coexistence are preserved.

Your config.json and character effects preferences are kept during launcher updates. Ore shrinking, dust and depletion styles are unchanged. Requires Native EveJS, the reviewed EVE client build3396210, and Launcher1.0.69 or newer. Launcher1.0.74 adds updater folder protection.

Verification: reviewed source guards, native mining/login boundary tests, client/UI replay tests, package/update checks, and the isolated official0.12.9-to-261018.1 upgrade. No new in-game rendering or performance measurement is claimed.
