Asteroid Erosion now has an in-game settings window at **MODS → Asteroid Erosion**.

Also fixes the missing depletion dust: EVE invalidated the removed rock's
position, sending the final cloud off-grid. The departing remnant and dust now
keep a valid native position until their animations finish.

- Choose **Dust & crumble**, **Burning**, **Burn + dust**, or **Quiet finish**.
- Adjust mining dust, strength, smooth shrinking and timing. Fine tuning adds
  dust lifetime, final shrink time and the maximum number of dusty rocks.
- **Apply** saves personal choices for this character in this client profile.
- Burning keeps EVE's original animation and native timing.
- Optional dust failures no longer risk preventing the final native release.

**Launcher updates are included from 0.2.0 onward.** Updates preserve
`config.json`; personal visual settings remain in EVE's own settings. Future tag
releases automatically build and verify the ZIP, matching `.update.json` and
checksums before publication.

Requires **EveJS 0.12.9 Native** and **EveJS Launcher 1.0.69 or newer**.

**Upgrading from 0.1.6:** close clients and stop the Game server; back up the old
mod's `config.json`; remove the old version through the Launcher; Add ZIP for
0.2.0; restore your config while the new mod is disabled; then enable it and
restart the server and clients. Add ZIP alone does not migrate the old config.
Subsequent versions use the Launcher's mod update controls.

Validated with GridCheck, the native EVE client, focused client/UI/server checks,
and the real Launcher updater in isolated fixtures. See `VERIFICATION.md` for
the exact coverage and remaining limits. The linked older gameplay demo shows
the accepted 0.1.6 dust appearance.
