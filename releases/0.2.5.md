# Asteroid Erosion 0.2.5

Adds the reviewed **EveJS 261125.3 and 261126.2 Native** compatibility declarations,
fixing the Launcher's unsupported-version warning. Earlier supported versions
remain listed.

- Mining, shrinking, dust and depletion behavior are unchanged from 0.2.4.
- Server configuration and personal visual preferences are preserved.
- No mod save migration is required.

Checked against actual server source and the exact EVE 24.02 client code, with
focused native/client fixtures and a 261115.2 regression. New-client rendering
and full-process mining/restart acceptance remain unverified; no new Linux,
Wine/Proton or Docker runtime support is claimed.

**Update:** close EVE and stop the game server, update Asteroid Erosion through
the Launcher's **Mods** page, then start the server and fully reopen EVE.
For a new installation, use **Mods -> Add ZIP** with `AsteroidErosion-0.2.5.zip`.
